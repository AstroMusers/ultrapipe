ULTRApipe Documentation
====================================

How bright will known and candidate exoplanet hosts appear to ULTRASAT in its
near-ultraviolet band? We use ULTRApipe to combine stellar-color transformations
with three-dimensional dust maps, then compare the exoplanet science potential
of proposed fields. The pointing weights and parameterization are defined in
``utils.py``, so the assumptions behind a ranking stay in view.

The code is actively developed. See the `ULTRApipe repository
<https://github.com/AstroMusers/ultrapipe/>`_ for the current source.
